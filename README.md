# NyayLens

NyayLens is a data-driven platform for exploring and analyzing
Supreme Court of India judgments.

## Project Goals

- Explore Supreme Court judgment metadata
- Search and filter judgments
- Analyze trends across judgments
- Build useful legal-data visualizations
- Explore NLP techniques for legal text
- Provide an accessible interface for legal information

## Tech Stack

- Python
- Pandas
- Flask
- SQLite / PostgreSQL
- HTML/CSS/Bootstrap
- Scikit-learn
- Plotly

## Project Status

Currently in the data exploration phase.
